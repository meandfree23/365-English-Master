# PATTERN 365 — 데이터 작성 스펙

## 배경
365 English Master(정적 HTML 학습 대시보드)에 새 트랙 "PATTERN 365"를 추가한다. Phase 1은 Day 1–100, **1일 1패턴 · 하루 5문장 · 총 500문장**이다.
방법론 출처: 원어민 강사의 왕초보 회화 강의 소개 영상(방법론만 차용, 예문은 전부 새로 창작).

방법론 핵심
1. **원어민은 결론부터 말한다** — 뼈대(누가 + 무엇/어디)를 먼저 던진다.
2. **카메라 줌아웃 사고** — 뼈대(클로즈업) → 렌즈를 한 단계 빼며 정보(대상/장소/상태/시간/이유/목적…)를 꼬리표처럼 뒤에 얹는다 → 롱 센텐스 완성.
3. **뉘앙스 쌍** — 비슷한 패턴의 차이(I'm at vs I'm in, I want to vs I'd like to)를 함께 배운다.
4. **3초 안에 말하기 + 나만의 문장 3개** — 롤플레이로 즉답, 자기 문장으로 바꾸기.
5. **연음·강세** — 원어민은 단어를 뚝뚝 끊지 않는다 (I'm at → 아이맷, t는 살짝 삼킴).

## 출력 형식
파일: `data/pattern/<구간>.js` (Phase 1은 `sprint1.js`–`sprint5.js`). 반드시 아래 형태:

```js
window.patternData = Object.assign(window.patternData || {}, {
  "21": { ... },
  ...
});
```

**권장 작성법**: 임시 디렉터리에 Node 스크립트(빌더)를 만들어 JS 객체로 작성한 뒤 `JSON.stringify(obj, null, 2)`로 파일을 생성하라 (따옴표/이스케이프 오류 방지). 빌더 스크립트는 저장소에 넣지 않는다.

## Day 객체 스키마
| 필드 | 설명 |
|---|---|
| `v` | 이모지 1개 (패턴 이미지) |
| `vT` | 원어민 사고를 요약한 영어 2–3단어 (예: "Location Pin") |
| `vD` | 원어민 사고 설명 한국어 1–2문장, 90자 이내 |
| `governing` | `"Day N: [core] 한국어 한 줄"` — 시적이되 명확하게 (예: `Day 3: [I'm at ~] 지도 위의 한 점 — 내 위치부터 먼저 던진다`) |
| `core` | 패턴 표기 (예: `"I'm at ~"`) |
| `pair` | `{ "x": "대비 패턴", "note": "차이 설명 한국어 90자 이내" }` |
| `pron` | `{ "link": "연음 표기(‿ 사용) 예: I'm‿at", "kr": "한국어 근사 발음 예: 아이맷", "tip": "연음/약화/강세 팁 70자 이내" }` |
| `my3` | 나만의 문장 만들기 프롬프트 3개 (한국어, 예: `"지금 내가 있는 곳 + 누구와"`) |
| `sentences` | 정확히 5개 (아래 구조) |

## 5문장 구조 (매일 동일)
| # | `lens` | `eT` | 역할 |
|---|---|---|---|
| S1 | `"뼈대"` | `"Skeleton"` | 패턴의 가장 짧은 완성 문장. 클로즈업. |
| S2 | `"+ 렌즈명"` (예: `"+ 상태"`, `"+ 대상"`, `"+ 장소"`, `"+ 누구와"`, `"+ 시간"`, `"+ 이유"`, `"+ 목적"`, `"+ 방법"`, `"+ 빈도"`) | `"Zoom Out"` | **S1 문장 끝(마침표 앞)에 청크 하나를 덧붙인 문장.** `add` = 덧붙인 청크 |
| S3 | `"+ 렌즈명"` (S2와 다른 렌즈) | `"Full Shot"` | **S2 끝에 또 하나의 청크를 덧붙인 롱 센텐스.** `add` = 덧붙인 청크 |
| S4 | `"뉘앙스"` | 짧은 대비 라벨 (예: `"At vs In"`, `"Want vs I'd like"`) | `pair`의 차이가 드러나는 별도 문장. `n`에 차이를 설명 |
| S5 | `"롤플레이"` | `"Real Talk"` | 상대 질문(`q`, `qt`)에 **결론부터** 답하는 실전 문장. 8–16단어. |

### 줌아웃 사다리 규칙 (검증기가 강제)
- S2의 마침표/물음표를 뗀 문장은 S1(구두점 제외)로 **시작**해야 하고, `add`로 **끝나야** 한다.
- S3도 S2에 대해 같은 규칙.
- 예) S1 `I'm at the office.` → S2 `I'm at the office by myself.` (add: `by myself`) → S3 `I'm at the office by myself until seven tonight.` (add: `until seven tonight`)
- 질문형 패턴도 동일: `Can I sit here?` → `Can I sit here for a minute?` → `Can I sit here for a minute while I wait?`
- 덧붙인 결과는 반드시 자연스러운 원어민 영어여야 한다. 어색하면 S1을 바꿔라.

## 문장 객체 스키마
| 필드 | 설명 |
|---|---|
| `lens` | 위 표 참고 |
| `txt` | 영어 문장 (미국식 구어, 축약형 적극 사용, 큰따옴표 금지, 화자표기 금지) |
| `t` | 자연스러운 한국어 구어 번역 (번역투 금지, 상황에 맞게 반말/해요체) |
| `n` | 원어민 사고·뉘앙스 노트 한국어 60자 이내. 매번 다른 관점으로 (공식 반복 금지) |
| `s` | 상황 태그 한국어 2–4자 (예: "통화", "카페", "출근", "주말", "여행") |
| `g` | `"M"` 또는 `"F"` — 문장마다 번갈아 (홀수 Day는 F로 시작, 짝수 Day는 M으로 시작) |
| `eT` | 위 표 참고 |
| `eD` | 한국어 25자 이내 요약 (예: "뼈대 + 상태 렌즈") |
| `add` | S2/S3만: 덧붙인 꼬리 청크 (문장 끝 부분과 정확히 일치). S1/S4/S5는 `""` |
| `q`, `qt` | S5만: 상대가 던지는 영어 질문과 한국어 번역 |

## 품질 기준
- 상황을 다양하게: 집, 회사, 카페, 식당, 여행, 가족, 친구, 연인, 건강, 쇼핑, 운동, 취미, SNS, 날씨 등. 같은 명사 반복 최소화.
- 왕초보 대상이므로 어휘는 쉽게, 그러나 원어민이 실제로 하는 말.
- 한국어는 실제 한국 사람이 그 상황에서 하는 말처럼.
- 모든 `txt`는 고유해야 하며, 다른 스프린트와 겹치지 않도록 S1도 구체적으로 (예: "I'm tired." 대신 "I'm so tired today.").
- **원본 영상 예문 금지**: "gift for my son", "department store", "I'm at home alone right now", "I'm in a bad mood".
- 리뷰 Day(20, 40, 60, 80, 100): `core`는 `"REVIEW · Sprint N"` (Day 100은 `"GRADUATION · Day 100"`), 스프린트에서 배운 패턴 2–3개를 결합한 문장으로 같은 5단 구조를 따른다. `pair`는 스프린트 안의 헷갈리는 두 패턴 비교, `pron`은 스프린트 전체를 아우르는 연음 팁.

## 검증
작성 후 반드시 실행합니다.
```
node tools/validate-pattern.js            # data/pattern 전체
node tools/validate-pattern.js data/pattern/sprint1.js   # 파일 하나만
```
오류 0건이 될 때까지 고칩니다. 검증기는 줌아웃 사다리(S1 ⊂ S2 ⊂ S3), 필드 누락, 5문장 구조, 렌즈 라벨, 롤플레이 질문(q/qt), 문장 중복, 원본 영상 예문 사용 여부를 검사합니다.

Phase 1 패턴 목록은 [`Pattern365_Phase1_100.md`](./Pattern365_Phase1_100.md), 전체 설계는 [`Pattern365_Master_Plan.md`](./Pattern365_Master_Plan.md)를 참고하세요.
